模组版本：1.0.0

游戏版本：1.16

适用范围：客户端、服务器

Github开源项目：[暂不公开]



功能简介：

① 轻量化的功能组件，极简主义的代表！

② 当玩家正在聊天栏编辑文字的时候，玩家头顶会出现聊天栏内的实时内容，并以"..."结尾

③ 当玩家放弃编辑聊天栏内的文字后，玩家头顶带有"..."结尾的可视化文字会立即消失

④ 当玩家发送聊天栏的文字后，会去掉可视化聊天文字的"..."后缀，并将可视化聊天文字提高半格

⑤ 发送出去的可视化文字会在一段时间后自动消失，正在编辑的可视化文字不会消失

⑥ 玩家头顶最多同时出现两行可视化文字，即正在编辑的可视化文字和已发送出去的可视化文字

⑦ 正在输入的指令也会被显示

⑧ 玩家退出游戏后可视化文字会立刻消失

⑨ 可视化文字会紧跟着玩家，且可视化文字不会与玩家名称等其他文字重合

⑩ 增加了颜色字符&=§ (&+[1-9]为颜色、&+[r l o n m]为标识)
