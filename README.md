01 @+指定玩家名称 (例子："@Dev 你今天好帅鸭~") -> 艾特一名指定玩家，所有人可用

02 @+a (例子："@a 容我发言一下") -> 艾特全体玩家，管理员可用

03 @+r (例子："@r 送你一颗钻石") -> 随机艾特一名除自己以外的玩家，管理员可用



04 Tab自动填充 -> 输入@或者@+片段玩家名后按Tab可自动填充玩家，所有人可用(无提示词)

05 潜行(下蹲)+右键玩家 -> 可以实现快速艾特指定玩家，所有人可用

06 点击聊天栏说话人的名字 -> 可以实现快速艾特指定玩家，所有人可用

07 增加了聊天栏颜色符号&=§ -> &+[1-9/a-e]会增加颜色 || &+[l,n,o,m]会增加标识，所有人可用





08 [快捷键]Ctrl+a -> 快速艾特全体玩家，管理员可用

09 [快捷键]Ctrl+r -> 快速随机艾特一名玩家，管理员可用

10 [快捷键]~(不在聊天栏中则为填充，聊天栏中则为补充) -> 快速艾特聊天栏中最近发言的一名玩家，所有人可用

11 [快捷键]Ctrl+q -> 开启/关闭艾特免打扰模式，所有人可用



12 发出艾特的人会在聊天框里看到自己艾特的人的名字被标注颜色

13 被艾特到的人会在聊天框里看到仅自己的名字被标注颜色

14 被艾特到的人会收到弹幕提示

15 被艾特到的人会收到音效提示

16 免打扰模式下的人不会收到任何弹幕提示

17 免打扰模式下的人不会收到任何音效提示

18 免打扰模式下的人在聊天栏中的名字不会被标注强调色
