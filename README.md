模组名称：可编辑的恶意高频Kill检测并保护

模组版本：1.0

游戏版本：1.16-1.17

作用范围：客户端、服务端



功能简介：

① 指令/set-killprotect-time：查看当前平均kill保护时长(所有人可用)

② 指令/set-killprotect-time [1-10]：设置平均kill保护时长(仅服主或局域网主可用)

③ 指令/set-killprotect-mistake：查看当前kill保护容错(所有人可用)

④ 指令/set-killprotect-mistake [0-99]：设置kill保护容错(仅服主或局域网主可用)

⑤ 指令/un-kill-protect：查看不被kill保护的玩家名单(所有人可用)

⑥ 指令/un-kill-protect [玩家名/可用@a等选择器]：添加/移除不被kill保护玩家(仅服主或局域网主可用)

⑦ 指令/log-kill-protect：查看kill保护日志，并保存到本地

⑧ 快捷键R：快速查看kill保护日志，并保存到本地

⑨ 平均kill保护时长：取玩家最近受到的几次kill的间隔取平均值，进而判断玩家是否受到恶意高频kill，值越大越安全

 kill保护容错：可理解为短时间内允许的高频kill的次数，值越小越安全，为0时玩家不会因kill而死亡

⑩ 可知晓执行kill指令的类型(玩家/命令方块)以及其坐标



相比于其他的类似模组更好在哪？

②其他：冗杂的逻辑，可能会影响游戏的性能。

 这个：在默认了最优数值的前提下，提供了两个可修改的重要参数，以应对各种游戏情况。
